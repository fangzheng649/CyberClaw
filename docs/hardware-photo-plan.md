# 硬件设备拍摄与配置界面方案

> 用于选拔赛文档第四章"物理IoT设备部署"。核心思路：**每个设备 = 实物照片 + Web 管理界面 配对**，体现"物理层 → 逻辑层"完整部署链路，技术含量高、可信度高。

## 一、总体拍摄原则（专业感）

| 维度 | 要求 | 原因 |
|------|------|------|
| 背景 | 纯黑布/深灰卡纸 | 消除杂乱背景，匹配赛博暗色主题 |
| 光照 | 双灯 45° 平光，或靠窗自然光 | 避免单灯硬阴影；**禁用闪光灯**（过曝反光） |
| 角度 | 30°–45° 斜侧拍，非纯俯拍 | 立体感，看清面板接口 |
| 景深 | 手机"人像模式"虚化背景 | 突出主体，专业质感 |
| 线缆 | 网线理顺、扎带固定 | 凌乱线缆是"业余感"第一来源 |
| 标注 | 拍照前贴临时标签，或后期用 Snipaste/PPT 加引线标注 | 指明 Port1/2/3、IP、设备角色 |
| 分辨率 | 原始高清（>3000px），后期再裁剪 | 保证印刷清晰 |

## 四、逐图拍摄/截取操作

### 图4-2a 实验平台全景
- **拍法**：俯拍 45°，交换机居中，两摄像头左右，NVR 下方，线缆理顺
- **要点**：黑底，双灯，能看到所有设备和连接关系
- **后期**：可加引线标注"交换机 / 摄像头×2 / NVR / 网线"

### 图4-2b TP-LINK 交换机（实物 + 配置）
- **左：实物特写**
  - 30° 斜拍正面，露出 Port 1/2/3 网口指示灯（亮=有数据）
  - 标注 Port1→摄像头A、Port2→摄像头B、Port3→NVR
- **右：Web 管理界面（二选一或拼两张）**
  - 浏览器开 http://192.168.1.1，登录后截：
    - **端口状态页**：显示 Port1/2/3 状态"已连接"+ 速率 1000M（证明真实拓扑）
    - **PoE 供电页**：显示 Port1/2 各供电 12V/0.5A（证明 PoE 供电摄像头）
  - F11 全屏，隐藏书签栏，深色主题更佳
- **合成**：左右拼，中间加"→"箭头，标题"TP-LINK TL-SG2210LPF 可管理 PoE 交换机"

### 图4-2c 海康摄像头（实物 + 配置 + 画面）三联
- **左：实物特写**
  - 摄像头正面，露出镜头 + PoE 网口
  - 标注型号 DS-2CD1023G2-L
- **中：Web 网络配置界面**
  - http://192.168.1.11 登录 → 网络 → 基本配置
  - 截 IP(192.168.1.11)/网关/RTSP端口(554)/ONVIF 配置页
  - 这张直接证明"设备真实联网 + RTSP 视频流"
- **右：实时画面**
  - Web 界面的"实时预览"，能看到真实监控画面（非常有说服力）
  - 或截 CyberClaw 后端 RTSP 拉到的画面
- **合成**：三联横排，标题"海康威视 DS-2CD1023G2-L 网络摄像头"

### 图4-2d NVR 录像机（实物 + 配置）
- **左：实物特写**
  - 正面斜拍，露出 8 口 PoE + 上行口
  - 标注 Port 接线
- **右：Web 通道管理界面**
  - http://192.168.1.60 登录
  - 截"通道管理"页：显示 2 路摄像头已注册（IPC-Entrance / IPC-Lobby）
  - 或"实时预览"多画面网格
- **合成**：左右拼，标题"海康威视 DS-7108N-F1 网络录像机"

### 图4-2e 网络配置图（替代纯拓扑）
- **方案 A（推荐）**：直接截 CyberClaw 3D HUD 的拓扑视图，设备节点显示真实 IP，连线显示端口关系——证明"物理设备已被平台纳管"
- **方案 B**：手画一张 IP 分配表 + 端口映射表（PPT），列清设备/IP/MAC/接交换机哪个口

## 五、配置界面截图技巧（统一专业感）

| 要点 | 操作 |
|------|------|
| 浏览器 | 全屏 F11，隐藏书签栏（Ctrl+Shift+B） |
| 缩放 | Ctrl+放大到 110%-125%，让内容饱满不留大片空白 |
| 主题 | 设备 UI 支持深色就切深色，统一赛博风格 |
| 裁剪 | 截掉浏览器标签栏、地址栏，只留页面内容 |
| 脱敏 | 账号密码框、序列号按需打码 |
| 标注 | 用红色/青色框 + 引线标注关键项（IP、端口、PoE 功率） |
| 统一边框 | 所有截图加 1px 同色边框，视觉统一 |

## 六、推荐工具

| 用途 | 工具 |
|------|------|
| 实物拍摄 | 手机主摄 + 人像模式（虚化）；光线不足用台灯补光 |
| 屏幕截图 | Win+Shift+S |
| 长截图（配置树展开） | Chrome 插件 GoFullPage |
| 合成排版 | PPT（最快，可加标注/箭头/标题） |
| 标注引线 | Snipaste 或 PPT 形状 |

## 七、拍摄顺序建议

1. **先拍全景（4-2a）**——所有设备就位、线缆理好后俯拍
2. **再逐个拍实物特写**（4-2b/c/d 左半）——同一光照下一次性拍完
3. **最后截配置界面**（4-2b/c/d 右半）——依次登录三台设备 Web UI 截图
4. **PPT 合成 + 标注**

> 💡 **加分项**：在 NVR/摄像头实时画面里，可以摆一张写有"CyberClaw 安全验证"的纸条入镜，直接坐实"这是我现场部署的真实环境"，防质疑。
