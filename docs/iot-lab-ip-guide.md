# CyberClaw IoT 实验室 — 设备 IP 配置指南

## 1. 总体网络拓扑

实验室有两个网段，笔记本同时连接两边（双网卡）作为桥梁：

```
   ┌──────────────────────────────────────────────┐
   │  交换机网段：192.168.1.0/24                    │
   │                                              │
   │   交换机 (192.168.1.1)                        │
   │     ├── 摄像头1 (192.168.1.11)                │
   │     ├── 摄像头2 (192.168.1.12)                │
   │     ├── NVR     (192.168.1.60)                │
   │     └── 笔记本有线口 (192.168.1.100)  ◄──桥──┐ │
   └──────────────────────────────────────────────┼─┘
                                                  │
   ┌──────────────────────────────────────────────┼─┐
   │  WiFi 网段：10.168.9.0/24（手机热点 iQOO Neo9）│ │
   │                                              │ │
   │   笔记本 WiFi (10.168.9.244)  ◄──────────────┘ │
   │     └── ESP32+DHT22 (10.168.9.x，DHCP)         │
   └──────────────────────────────────────────────┘

   笔记本：双网在线，运行 MQTT broker + CyberClaw，能同时够到两边
```

## 2. IP 分配总表

| 设备 | IP | 子网掩码 | 网关 | 接入方式 |
|------|-----|---------|------|---------|
| TP-LINK 交换机 | 192.168.1.1 | 255.255.255.0 | — | 网线（核心） |
| 摄像头 1 | 192.168.1.11 | 255.255.255.0 | 192.168.1.1 | 网线（PoE 供电） |
| 摄像头 2 | 192.168.1.12 | 255.255.255.0 | 192.168.1.1 | 网线（PoE 供电） |
| NVR 录像机 | 192.168.1.60 | 255.255.255.0 | 192.168.1.1 | 网线（LAN 口） |
| 笔记本（有线） | 192.168.1.100 | 255.255.255.0 | 192.168.1.1 | 网线 |
| 笔记本（WiFi） | 10.168.9.244 | 255.255.255.0 | 10.168.9.243 | WiFi |
| ESP32 | 10.168.9.x（DHCP） | 255.255.255.0 | 10.168.9.243 | WiFi |

> MQTT broker 跑在笔记本上，监听 `0.0.0.0:1883`，两个网段都能访问。

## 3. 各设备配置/验证方法

### 3.1 交换机（192.168.1.1）

**验证：** 浏览器开 `http://192.168.1.1`，能进管理界面 = OK。

**重置/修改：**（默认 IP 是 192.168.0.1，首次配置要把笔记本网卡设成 192.168.0.x 才能进）
1. 进管理界面 → 系统管理 → IP 管理
2. 改 IP 为 192.168.1.1，掩码 255.255.255.0
3. **⚠️ 必须点「配置保存」菜单保存！否则断电丢失**

### 3.2 摄像头（192.168.1.11 / .12）

**验证：**
```cmd
ping 192.168.1.11
ping 192.168.1.12
```
浏览器开 `http://192.168.1.11` 能看到海康登录页 = OK。

**修改：** 用 **SADP Tool**（海康官方工具）改：勾选设备 → 改 IP → 输密码 → 修改。摄像头 flash 永久保存，断电不丢。

### 3.3 NVR（192.168.1.60）

**验证：**
```cmd
ping 192.168.1.60
```
浏览器开 `http://192.168.1.60` = OK。

**修改：** SADP Tool 改，或 NVR Web 界面里「配置 → 网络 → 基本配置 → TCP/IP」。永久保存。

### 3.4 笔记本有线网卡（192.168.1.100）

**验证：**
```cmd
ipconfig
```
看「以太网适配器」段，IPv4 应为 192.168.1.100。

**设置（Windows）：**
1. `Win+I` → 网络和 Internet → 以太网
2. 点当前以太网 → IP 分配 → 编辑 → 手动
3. IPv4 开启：IP `192.168.1.100` / 掩码 `255.255.255.0` / 网关 `192.168.1.1`
4. 保存

**命令行（管理员 cmd）：**
```cmd
netsh interface ip set address name="以太网" static 192.168.1.100 255.255.255.0 192.168.1.1
```
（`name=` 改成 ipconfig 里实际显示的适配器名）

### 3.5 ESP32（WiFi，DHCP）

**验证：** ESP32 上电后串口会打印它分到的 IP（如 10.168.9.229）。

**配置在固件里：** `firmware/esp32-dht22/src/main.cpp` 顶部：
```cpp
const char* WIFI_SSID     = "iQOO Neo9";      // WiFi 名
const char* WIFI_PASSWORD = "20041129";       // 密码
const char* MQTT_BROKER = "10.168.9.244";     // 笔记本 WiFi IP
```
改了 WiFi 信息要重新烧录。上电自动连接，无需手动操作。

## 4. 重启后操作清单

每次全部断电重启后，按顺序做：

1. **开交换机电源** → 等 10 秒
2. **开笔记本** → 确认 WiFi 连上 iQOO Neo9 热点 + 网线连交换机
3. **确认手机热点开着**（ESP32 靠它）
4. **开 NVR 电源**（NVR 自带电源，不是 PoE）
5. 摄像头由交换机 PoE 供电，交换机开了就自动启动
6. **ESP32 上电**（USB 接电源或笔记本）→ 自动连 WiFi
7. **启动 broker**：双击 `firmware/mqtt-broker/start_broker.bat`
8. 验证全部连通：
   ```cmd
   ping 192.168.1.1
   ping 192.168.1.11
   ping 192.168.1.12
   ping 192.168.1.60
   ```

> 摄像头/NVR/交换机/笔记本的 IP 都不会变，只有 ESP32 的 IP 可能因 DHCP 变（用 nmap 或串口查新 IP）。

## 5. 升级建议：统一到一个网段（可选）

当前 ESP32 在手机热点（10.168.9.x），其余在交换机（192.168.1.x），靠笔记本双网桥接。这个方案能用，但有缺点：
- ESP32 IP 会变（DHCP）
- 依赖手机热点
- 两个网段不直观

**更干净的方案：买个 WiFi 路由器接交换机的 LAN 口**，让路由器也发 192.168.1.x 的 WiFi：
- ESP32 连路由器 WiFi → 分到 192.168.1.x（如 .21）
- 所有设备同网段，笔记本单网即可
- ESP32 IP 可设静态，永不变

这样整个实验室就是一个干净的 192.168.1.0/24 网络。
